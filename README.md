# Python Basics to Advanced

This repository contains my Python practice work, arranged in the order I plan to study it.

The lessons are grouped into three stages:

- `beginner/` covers the language basics and common data structures.
- `intermediate/` moves into functions, files, errors, modules, and OOP.
- `advanced/` is for algorithms, APIs, databases, concurrency, testing, and packaging.

Projects are kept under `projects/`, and useful notes or references go in `resources/`. Each study day has its own folder, so examples and exercises can be added without making the repository difficult to browse.

Day 01 is not included in this version of the repository.

The lessons use Python's standard library unless a project needs an external package. Repository-level dependencies will be listed in `requirements.txt`; larger projects may have their own dependency file.
